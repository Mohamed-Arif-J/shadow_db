# ShadowDB 🛡️

**Autonomous Text-to-SQL Agent with Schema Sandboxing & Self-Healing Execution**

ShadowDB protects production databases from destructive DDL/DML accidents, hallucinations, and unoptimized queries generated by Large Language Models. By intercepting user queries and validating them inside an ephemeral, disposable sandbox (SQLite, DuckDB, or isolated PostgreSQL snapshots) before dispatching them to read replicas, ShadowDB delivers enterprise-grade guardrails for autonomous data agents.

---

## ⚡ Key Features

- **Schema Sandboxing:** Runs queries inside isolated, in-memory clones populated with synthetic seed rows or truncated schemas. If a query crashes or causes locks, production remains untouched.
- **AST Safety Linter:** Parses every query with `sqlglot` prior to execution. Automatically blocks unpermitted mutations (`DROP`, `TRUNCATE`, unfiltered `DELETE`), enforces row-limit boundaries (`LIMIT 1000`), and verifies read-only integrity.
- **Self-Healing Error Loop:** Intercepts runtime sandbox failures (syntax bugs, type casting errors, schema mismatches) and feeds dialect-specific error traces directly back into the LLM for automatic query correction.
- **Cost & Performance Pre-Flight Checks:** Inspects `EXPLAIN` execution plans inside the sandbox to catch Cartesian joins, missing index penalties, and full sequential scans before they hit live data.
- **Dialect Agnostic:** Seamless translation and verification support for PostgreSQL, SQLite, DuckDB, MySQL, and Snowflake.

## 🚀 Quickstart

### 1. Installation

```bash
pip install shadowdb
```

Or install from source:

```bash
git clone https://github.com/your-org/shadowdb.git
cd shadowdb
pip install -e .
```

### 2. Environment Variables

Create a `.env` file or export your credentials:

```bash
OPENAI_API_KEY="your-llm-api-key"
DATABASE_URL="postgresql://reader:password@production-read-replica.internal:5432/analytics"
SHADOW_BACKEND="duckdb" # Options: sqlite | duckdb | postgres_cow
```

### 3. Basic Usage

```python
import os
from shadowdb import ShadowDBAgent, ShadowConfig

# 1. Initialize Sandbox Configuration
config = ShadowConfig(
    sandbox_engine="duckdb",
    max_retries=3,
    enforce_limit=1000,
    allow_mutations=False
)

# 2. Spin up the Agent
agent = ShadowDBAgent(
    db_url=os.getenv("DATABASE_URL"),
    llm_model="gpt-4o",
    config=config
)

# 3. Synchronize Schema into the In-Memory Sandbox
agent.sync_sandbox_schema(sample_rows=20)

# 4. Ask questions safely
response = agent.ask("Which 5 customers generated the highest revenue in Q3?")

print("Generated SQL:\n", response.sql)
print("Query Plan Safe:", response.is_safe)
print("Data Summary:\n", response.summary)
```

## 🔒 Sandboxing Strategies

| Mode | Backend | Startup Overhead | Fidelity | Best Use Case |
| :--- | :--- | :--- | :--- | :--- |
| `duckdb` (Default) | In-Memory DuckDB | `< 5ms` | High (OLAP standard) | High-speed analytical queries and aggregations. |
| `sqlite` | In-Memory SQLite | `< 2ms` | Moderate (OLTP base) | Lightweight local testing and transactional queries. |
| `postgres_cow` | Ephemeral Docker / Neon Branch | `100–300ms` | 100% (Identical engine) | Complex PostgreSQL workloads with custom extensions, JSONB, and PostGIS. |

## 🛡️ AST Guardrail Configuration

ShadowDB enforces strict policy rules on generated queries before any execution takes place:

```python
from shadowdb.guards import ASTPolicy

policy = ASTPolicy(
    prohibited_statements=["DROP", "TRUNCATE", "ALTER", "GRANT", "REVOKE"],
    enforce_read_only=True,
    max_execution_time_ms=5000,
    require_where_on_delete=True
)
```

## 🛠️ Self-Correction Mechanism

When an error occurs during sandbox testing, ShadowDB collects:
1. The original natural language prompt.
2. The failing SQL snippet.
3. The exact database compiler trace (e.g., `Binder Error: Referenced column "sales_rev" not found in table "orders"`).
4. Relevant table DDL snippets.

The reflection harness reformulates the prompt to rectify the syntax and attempts sandbox validation again, looping up to `max_retries` before surfacing an issue to the user.
